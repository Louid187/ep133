KO SIM

An unofficial, browser-based simulator of an EP-133 style sampler / sequencer.

Tip on iPhone/iPad: turn the silent switch off or raise the volume. Use “Add to Home Screen” for a full-screen app.

How to use

Basics

  • Pads play the 12 sounds of the current group.
  • A B C D select a group (drums, bass, melodic, fx/loops).
  • ▶ play / stop. ● arm record, then play pads to record live (quantised by TIMING).
  • KEYS plays the selected sound chromatically on all pads. − / + change octave.
  • Knob X / Y: drag up/down (or scroll). Their function depends on the screen.
  • Fader: controls the parameter chosen with FADER + pad for the current group.

Patterns & scenes

  • Hold group + − / +: change that group's pattern (1–99).
  • Hold group + knob X: pattern length in bars (1–16).
  • On MAIN, − / + select scene. Going past the last scene creates a new one (copy).
  • SHIFT + ▶: song mode — plays scenes 1…n in order.
  • SHIFT + COPY: duplicate current pattern into the next free slot.

Sound

  • SOUND: edit the last played pad. − / + flip pages, knobs edit values (level, pitch, pan, attack, release, start, end, play mode, choke, reverse).
  • SHIFT + SOUND: browse the library; knob X or − / + assigns a new sample to the pad.
  • SAMPLE: sampling screen. Hold a pad (or hold SAMPLE + pad) to record from the mic or resample the output.
  • SHIFT + SAMPLE: import an audio file to the selected pad.
  • COPY, pad, pad: copy a sound.

Timing, FX, erase

  • TIMING: knob X quantise, knob Y note-repeat rate. Hold TIMING + pad for note repeat.
  • SHIFT + TIMING: step editor — tap steps on the screen, knob X/Y move cursor/bar.
  • FX: choose master FX (− / +), knobs set parameters, fader = send for the group.
  • Hold FX + pad: punch-in effects (loops, delays, filters, crush, reverse…).
  • Hold ERASE + pad: remove that pad's notes. ERASE + group: clear pattern. SHIFT + ERASE: undo.
  • SHIFT + pad / group: mute. TEMPO: knob X bpm, knob Y swing, tap repeatedly to tap-tempo. SHIFT + TEMPO: metronome.
  • SHIFT + MAIN: projects 1–9 (auto-saved in this browser).

KO Sim is an unofficial fan simulator for trying out the workflow. It is not affiliated with or endorsed by teenage engineering; all sounds are synthesised in your browser. The real device's controls and features differ in places.
